🎯 **What:** The arbitrary file read/write vulnerability (path traversal) in `load_project` and `save_project` commands has been fixed.
⚠️ **Risk:** The previous implementation used the `path` parameter without validation, allowing a malicious actor (or compromised frontend) to read or write files outside the intended directories, potentially leading to data exfiltration or system compromise.
🛡️ **Solution:** Integrated `tauri-plugin-fs` to enforce file system scoping. The `path` provided to `load_project` and `save_project` is now validated against the app's allowed file system scope using `app.fs_scope().is_allowed(Path::new(&path))`. Access to files outside the permitted scope is denied, returning a permissions error.
